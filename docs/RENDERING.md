# 渲染说明

> 本文档同时提供[英文版](RENDERING.en.md)。

物品图标采用同轴直管的居中正交渲染，两端为相同的管箍。长度约为管箍直径的 2.1 倍，轮廓占格宽的 90%。半透明蓝色管壁在 80 像素的库存图集中仍保持可见覆盖。黑白抠像从透明渲染中重建直通 alpha 像素。`pwsh tests/run.ps1 -RenderIcon` 从 `../tests/PipeIconRender.cs` 的参数化模型重新生成 `../screenshots/pipe-icon-orthographic.png`；`assets-src/fluid-pipe.png` 是内嵌的源图像。`pwsh tests/run.ps1 -IconOnly` 检查内嵌图标和原生图集注册。

阀门拥有独立的物品与配方图标，包含银色阀体、两个玻璃接口和橙色手轮。同一渲染器导出 `../screenshots/pipe-valve-icon-orthographic.png`；`assets-src/fluid-valve.png` 是其内嵌源图像。两个图标模型共用玻璃反射曝光。`PipeVisuals` 配置世界材质。

世界中的阀门采用程序化外壳，具有圆润的轴向阀体、倒角金属法兰、凹陷紧固件、一体式顶部执行器和低矮安装底座。两个接口位于同一中心线上，相距 1.2 世界单位；青色标识 A 侧，琥珀色标识 B 侧。接口高度与管道中心线一致。平滑的径向法线保持圆柱反射连续，轮廓边则界定法兰倒角和开放内孔。五个原生 GPU 材质组划分外壳、钢材、面板和接口标记。模型保持在下一级运输建筑的高度之下。原生实例渲染、建造预览和碰撞使用注册的原型几何。

程序化网格跟随实际连接生成。内置液体管道的直径为 0.64 世界单位，中心线位于原生运输锚点上方 0.34 单位。32 边玻璃管壁在 92% 外半径处具有朝向内侧的表面。共线管段共享连续的透明表面。弯头和多分支交汇使用不透明钢材，其分支与相邻管道相接处为空心倒角管箍。交汇处采用圆角管形状的平滑并集。凸形交汇处使交汇点内缩并使分支弯曲，同时保持与相邻管道相切。混合在射线原点处淡出，以保持外半径。自由端为圆角玻璃端头，带钢制压边圈。孤立节点是带两个圆角端头的短透明圆柱；相邻连接方向决定其重新生成的形状。在 BepInEx 配置中设置 `Appearance.MetalFittings = false` 后，重启游戏即选用透明接头表面。

所有流体共用同一个管道物品和同一份玻璃管壁材质。内部流体体积从 `IconSet.itemDescArr` 读取所存物品的原生储液罐调色板：每个 40 个 float 的描述符在偏移 20 处保存 `IconDesc.reserved0`。储液罐着色器的 sRGB 转换和 1.5 曝光生成线性 HDR 色调，并上传到 1 像素的 RGBAHalf 纹理。调色板变化时替换色调纹理，同时保持材质与几何的归属不变。储液罐调色板未设置时，其它物品类型使用描述符的面颜色；缺失描述符时使用中性灰。空网络显示轻微着色的透明管壁。

管道检视器通过独立的描边通道把当前节点渲染为绿色，把直接相邻节点渲染为青色。选中节点使用游戏的描边通道；额外的通道使用克隆的原生材质和渲染器的临时缓冲区合成相邻节点。遮罩跟随缓存的玻璃管壁、接头和机器接口几何。原生降采样与合成提供与其它选中建筑相同的轮廓处理。关闭检视器时释放其节点网格。

管壁使用游戏的通用 PBR 玻璃着色器，管壁轻微着色，具有均匀的高平滑度、镜面反射和储液罐的边缘色调。较低的逐表面不透明度使掠射角下透过两个玻璃界面仍可见。储液罐顶点动画依赖储液罐几何；通用玻璃着色器可接受任意管道网格。钢制接头使用 Standard 金属着色器，金属度 0.98、平滑度 0.86。共享的 64 像素 HDR 立方体贴图近似天空、地平线和地面照明，通过材质属性块限定到管道绘制。该贴图按活跃工厂各生成一次，取自近似的环境颜色。不透明接头包含朝向内侧且法线翻转的三角形，使其内部在透过相邻管道开口观察时遮挡背景。内部体积使用无光照透明色调纹理，颜色不受表面朝向和阳光影响。共享边界框架连接相邻的玻璃环和流体环。玻璃内部在所有外部管壁之前渲染，包括跨空间区块的情况，以保持透明层顺序。玻璃和流体使用无阴影透明通道；钢材接受直接光照和阴影。Standard 材质提供管壁回退。含流体的分量显示均匀的完整截面，其材质由物品身份决定。

网格按空间区块、注册的管道类型和扩展的语义组缓存，并进行视锥剔除。库存变化复用几何，并按网络选择材质。连接变化重建受影响的外围区块，并使缓存的流体组网格失效。渲染器按空间区块分组提交缓存的网格。

注册类型通过 `PipeGeometryProfile` 配置管壁半径、中心高度、接头比例和可选支撑环。共享边界位置兼顾两个节点的中心高度。在半径不一致的边界处，较大一侧提供不透明倒角过渡管，其内部带锥形衬里。碰撞包围范围、选择网格、机器接口和分拣器鞍座遵循注册尺寸。内置流体类型保持上述尺寸。

自定义尺寸把原生建筑重叠查询调整为管道中心线、半径和独立长度。发生变化的节点及其邻居把碰撞体更新排入主线程；包围范围实际变化时使原生碰撞代理失效。类型升级成功后还会使下一层邻接失效，因为中心高度变化可能移动邻居远端点的接头归属。

`PipeAppearance` 分配独立拥有的表面材质和可选内芯。纹理坐标回调把世界位置映射为纵向 UV 坐标；其输入在空间区块边界处保持稳定。动画效果为每次表面绘制使用已清空的 `MaterialPropertyBlock`，并保留缓存的几何。扩展提供的纹理资源仍归该扩展所有。回调失败时选用缓存回退行为，并为每个失败的回调与类型各生成一条诊断。

结构类型可通过 `PipeAppearance.interior` 提供 `PipeInteriorProfile`。其 `Members` 属性暴露 1–16 个不可变 `PipeInteriorMember` 对象的只读快照。每个成员指定一个有限 `Vector2` 偏移、一个不可变 `PipeInteriorSection`，以及 `Core` 或 `Fittings` 表面角色之一。`Circle` 接受 `[0.01, 0.85]` 范围内的半径比例。`RoundedRectangle` 接受 `[0.02, 1.7]` 范围内的全宽与全高比例，圆角半径从零到较小边的一半。尺寸按外管壁半径归一化。包络约束为 `offset.magnitude + section.RadiusFraction < 0.9`；矩形截面用其对角线的一半作为保守包围半径。在共享端点处，X 沿路径切线与径向上方向的叉积，Y 沿径向上方向在截面平面内的投影。配置截面后自动启用 `HasCore`。省略截面时，`hasCore` 和 `coreRadiusFraction` 保持单导体行为。公开构造示例见 [管道类型与外观扩展](PIPE_TYPES.md#内部纵向构件)。

有向截面遵循原生输入到输出的方向，且可以不对称。无向截面配置要求 `(x, y)` 与 `(-x, y)` 成员一一匹配，包括截面种类、全宽、全高、圆角半径和表面角色。重复成员需要有相同数量的镜像。路径反向会翻转 X，径向 Y 保持其朝向。类型构造时校验这一对称性，从而允许带独立上方净空的较低底板。纵向构件沿实际路径延伸，使用共享端点的切线与径向框架，包括跨球面管段的情况。圆角矩形扫掠平直侧壁和圆弧转角，自由端使用平面封盖。分支节点为每个连接臂生成一段截面。节点几何缓存包含类型身份、端点位置、框架、接头归属和有向内部朝向。拓扑与类型变化使受影响的几何失效；动画更新材质属性。内部子网格 0 使用 `Core` 绘制，子网格 1 使用 `Fittings` 绘制；空表面跳过。

`PipeWallMode.Open` 要求 `Structure` 行为并需要内部截面配置。其绘制批次包含已配置的构件，省略管壁、内壁和外封盖几何。选择描边包含可见的 `Core` 和 `Fittings` 构件。碰撞包围范围继续使用配置的几何包络。开敞截面可组合两侧箱梁、底板和导体，同时保留通畅的中央通道。

封闭的环形结构可使用周期性世界位置映射，使纵向纹理跨区块边界保持连续。对于周长 `C` 和目标世界重复长度 `L`，扩展可取 `N = max(1, round(C / L))`，把经度映射为 `atan2(z, x) / (2π) * P`，并设置 `textureCoordinatePeriod = P`。渲染器把相邻截面展开到最近的相位。扩展应用 `N / P` 的纵向纹理缩放，实际重复长度为 `C / N`；整数重复次数可闭合整圈接缝。该圆环内的所有批次使用相同的周长和映射。动画把世界速度除以 `C / N`，换算为每秒纹理周期数。

环向 U 按归一化的周长距离取值。圆形截面使用均匀角度步长；圆角矩形累加直边长度和圆角弧长，使两种表面的纹理密度保持一致。接缝顶点在 U = 0 和 U = 1 处共享位置，使插值局限在各自一侧。平面端盖使用独立的平面投影。

七参数 `PipeAppearance` 构造函数仍是二进制契约：`(PipeWallMode, Action<PipeMaterialSet>, bool, float, Action<PipeEffectContext, MaterialPropertyBlock>, Func<Vector3, float>, float)`。该重载的七个参数均为必填，并委托到 `interior: null` 的八参数构造。八参数重载保留可选参数，包括末尾的 `PipeInteriorProfile interior = null`。反射测试校验保留的签名及其参数可选性。

圆形 `PipeInteriorMember(Vector2, float, PipeSurfaceRole)` 构造函数同样保留其二进制签名，并通过 `PipeInteriorSection.Circle` 委托。截面重载接受 `(Vector2, PipeInteriorSection, PipeSurfaceRole)`。

`PipeTypeDefinition` 保留其七参数签名 `(string, ItemProto, PipeAppearance, PipeBehavior, string, Func<PlanetFactory, int, int>, PipeDirectionMode)`。这些必填参数委托到 `geometry: null` 的八参数构造；源码调用方可通过八参数重载提供可选的几何配置。

可选的直连机器接口采用程序化矩形机壳，具有倒角边框、凹陷前面板和短的圆形管道插口。共享周界截面使机壳开口和插口与管道同轴，包括高位接近的情况。前面边框上有四个建模紧固件。外壳、边框和插口颈部使用白色介电表面，平滑度适中。炭灰色嵌板和银色压边圈界定开口。所有不透明表面共享缓存的空间区块网格。

已建成的液体分拣器保留其等级对应的原生固定端点外壳网格和 UV 坐标。其静态材质把原生 alpha 涂装遮罩和等级色调烘焙到缓存纹理中；白色和灰色框架表面保持其原有颜色。Standard 着色器接收金属/平滑度贴图、共享环境反射，以及为阴影可见性提供的中性微弱自发光贡献。管道鞍座沿管道跨度为 0.29 世界单位，分支插口半径为 0.165。程序化等级色带读取原生机身材质的 `_Color`，并使用介电涂装。方向标记占用独立的无光照子网格，并读取原生箭头材质的 `_TintColor`。标记强度跟随原生用电设备的电网供电比例：未供电的标记仍保留可辨识的等级色调，满供电时产生 HDR 光信号。供电变化更新材质属性块，并保留缓存的几何。白色介电支撑杆把端点框架连接到上部传输管外部的管箍。支撑杆和管箍保持在管组件的高度包络内。金属管段与压环、透明管壁、炭灰色电机表面、等级涂装、白色支撑件和方向标记分别占用独立的材质子网格。弯曲管端使用与相邻直段一致的显式切线，使接缝环垂直于共享中心线。

分拣器建造预览和待建建筑使用原生分拣器模型、全息虚影材质和 GPU 实例生命周期。程序化管道渲染在建造完成后开始。场景夹具在 60 个渲染帧内检查原生预览归属，并采集匹配的供电与未供电视图。运行时箭头测试在深色背景上渲染全部四个等级，测量可见性和依赖供电的亮度。

已建成的分拣器夹具从管道渲染器缓存的节点形状解析其中心和切线。原生货运路径锚点投影到可见直段或采样的弯头中心线上；分支挂接选择最近的臂，并以稳定的切线规则打破并列。注册半径和中心高度决定鞍座与颈部。库存更新复用这些形状。原生路径构造用路径切线初始化缺失的预览位姿；待建格点和拆除标记使用独立的径向框架。

`../screenshots/ingame` 包含已加载沙盒行星的离屏截图。成对布局在游戏相机和共享世界光照下，把原生 Conveyor Belt Mk.I 实体放在左侧，把充满水的管道实体放在右侧。场景包含直段、弯头、T 形交汇和高架段，中央放置原生空储液罐和充水储液罐以便材质对比。另有匹配的相机截图展示同一管道网络的空载与充水状态。近景截图对比孤立的空载与充水节点。普通传送带为空载。截图测试装置通过原生工厂实体与连接 API 创建场景。交互式放置由建造相关的夹具验证。

连接图库使用独立的 69 节点场景。远侧一排包含直段、弯头和斜 Y 形连接；近侧一排包含 T 形连接、垂直入口和八接口交汇。空载与充水截图使用相同的相机位姿和几何。

结构图库在蛇形、高架交叉和环形布局中对比原生传送带与管道。交叉管段处于不同高度层和不同连通分量。传送带环路有两个汇入分支，二者之间存在缺口：24 个顶点、24 条边和一个独立环。管道布局把该缺口闭合成 θ 图：25 个顶点、26 条边和两个独立环。完全由原生传送带构成的图中，每个顶点至多有一个输出连接，因此每个连通分量至多有一个独立环。

立方体夹具边长为 3 世界单位，具有 32 个管道节点，沿十二条边分布 36 条单位长边。其五个独立环共享同一库存。同机位空载/充水全景与角落截图，以及俯视/低角度空载视图，展示垂直连接和重叠的透明表面。注入 1,280 单位水并在一个节点抽取，验证全部 32 个节点即时可见。
