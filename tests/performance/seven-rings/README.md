# 七环渲染测量

场景为半径 200 的原生星球，4 个轨道连接组件环、2 个粒子加速轨道环、1 个星环电网环，每环 1000 节点。两个版本使用相同的节点位置和相机。图像尺寸为 1600×900，Direct3D 11，GPU 为 NVIDIA GeForce RTX 5090。测试进程关闭音频和垂直同步，使用独立文档目录。

每个视角预热 6 帧后采样 24 帧。主相机自动绘制在采样期间关闭，每帧显式绘制一次；读取一个像素等待 GPU 完成。`frame_ms` 来自 Unity 的非缩放帧间隔，包含模拟、提交和同步读回开销。该测量描述固定后台场景。

| 视角 | 基线平均整帧 ms | 优化版平均整帧 ms | 基线 P95 ms | 优化版 P95 ms | 基线轨道提交 ms | 优化版轨道提交 ms |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 近景 | 6.248 | 6.026 | 7.496 | 8.345 | 0.389 | 0.172 |
| 远景 | 11.741 | 6.256 | 12.974 | 7.045 | 1.720 | 0.696 |
| 行星视图 | 20.758 | 12.485 | 24.859 | 13.245 | 6.761 | 2.541 |

基线为初始可玩 profile 中的两个 DLL；优化版为 Fluid Pipes 0.10.1 与同步的星环适配程序集。对比包含网格、批次、遮挡剔除及外观密度变化：电网采用开放框架和绿色导线，框架间距约 24 世界单位，绝缘套节周期约 8 世界单位；粒子加速环间距约 48 世界单位，机匣尺寸保持其物理尺度。

渲染器使用封闭结构截面的单面三角形，省略零尺寸构件区间，按倒角尺度选择矩形截面采样数，并在绘制前跳过空子网格。结构批次使用 32 世界单位的分区，缓存实际网格包围盒；行星实体与包围球共同提供保守的遮挡判定。大圆环保留 96 点的周界采样。

所有稳态采样的网格重建计数增量均为零。行星视图的可见提交分区从 908 降到 370。缓存网格的数量还受到遮挡与首次可见状态影响；对应的顶点和三角形计数保存在原始日志中。

原始记录：`baseline.txt`、`optimized.txt`。

管道与星环的兼容验证使用 `tests/run-orbitalring.ps1`，覆盖物品准入、无尽水罐和建造栏。轨道模型与七环场景的验证入口位于 OrbitalRing 仓库的 `tests/run-orbital-visuals.ps1`。本目录保存 0.10.x 渲染器的原始测量记录，用于分析版本之间的变化。
