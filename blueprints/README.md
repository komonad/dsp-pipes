普通存档需要解锁管道、蓝图及足够的垂直建造科技。最高级垂直建造条件下，两份蓝图均通过原生预览碰撞检查、待建生成和实际建造验证。选择空旷位置放置；跨纬度区域时，原生蓝图系统会按当地网格调整横向尺寸。

蓝图保存建筑位置和连接，不包含库存、地基或光照。建成后点击每条独立管路，向共享库存放入流体即可着色；也可以用分拣器供料。没有连接的管路可以使用不同流体。

## 浑天仪配色

五个同心倾斜圆环的半径从外到内为 18、16.2、14.4、12.6、10.8，依次使用硫酸、水、重氢、精炼油、原油。中心两个互锁环分别使用氢和精炼油，底部水平环使用水。八条管路彼此独立。

## 双螺旋塔配色

两条半径 6.4 的螺旋分别使用水和重氢，各上升 42 单位、旋转三圈。底部、中部和顶部三个独立水平环使用硫酸。
