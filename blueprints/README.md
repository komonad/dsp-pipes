# 玻璃管奇观蓝图

这些文件是游戏原生 `BLUEPRINT:` 文本，管道的完整连接图保存在同一份文本中。安装本仓库构建的 FluidPipes 及其依赖、保留内置玻璃管道，将 `.txt` 放入游戏蓝图目录，或复制完整内容后在蓝图面板中从剪贴板导入。

| --- | ---: | ---: | ---: | --- |

普通存档需要解锁管道、蓝图及足够的垂直建造科技。最高级垂直建造条件下，蓝图通过原生预览碰撞检查、待建生成和实际建造验证。选择空旷位置放置；跨纬度区域时，原生蓝图系统会按当地网格调整横向尺寸。

蓝图保存所选节点之间的每条连接，支持多分叉、环路和未完成的待建节点。选区边界之外的边不复制。重复盖建可以补回缺失的边，并保留匹配的实体与库存；会混合不同流体的连接在放置前拒绝。

蓝图不包含库存、地基或光照。建成后点击每条独立管路，向共享库存放入流体即可着色；也可以用分拣器供料。

## 浑仪配色

| 管路 | 结构 | 流体 |
| --- | --- | --- |
| 固定框架 | 方形双层底座、四柱、地平环、子午双环、极轴 | 精炼油 |
| 赤道环 | 与极轴垂直的双环 | 水 |
| 黄道环 | 相对赤道环倾斜 23.4° | 硫酸 |
| 四游环与窥管 | 可见的双环与直径方向管段 | 重氢 |
| 中心球体 | 球形经纬骨架 | 氢 |

极轴仰角为 35°，五组管路相互独立。各环与轴的位置是固定的造型参数，不随星球纬度自动校准。

## 双螺旋塔与网格配色

双螺旋塔的两条半径 6.4 的螺旋分别使用水和重氢，各上升 42 单位、旋转三圈。底部、中部和顶部三个独立水平环使用硫酸。

立体网格包含 4×4×4 个单元，125 个交点通过采样管段形成六向交汇，全部节点共享一份水库存。
